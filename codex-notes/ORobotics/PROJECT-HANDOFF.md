## What the QR3D change implements

The long-lived printed QR code points to the case-sensitive URL:

https://www.orbitusrobotics.com/QR3D

The new content page declares the exact canonical route /QR3D/, which builds to
public/QR3D/index.html. Keep the uppercase spelling; a lowercase route is not
equivalent on GitHub Pages.

The landing page provides:

- A prominent link to the Orbitus Robotics home page.
- A secondary link to the Maker Faire and field gallery.
- Instagram, Facebook, X, and GitHub cards.
- A contact call to action.
- The existing QR artwork from static/images/Orbitusrobotics_AR3D.png.
- A mobile-first, high-contrast presentation with visible keyboard focus.
- A compact footer that avoids repeating the full social and navigation
  sections.

Social URLs and card copy are configured under params.social_media in
hugo.yaml. Each enabled entry supplies its URL, QR3D slug, label, badge, handle,
description, and accessible label. The QR3D template reads those values instead
of duplicating them.

The QR3D page deliberately uses a fixed dark presentation. Its front matter
hides the global theme toggle because the toggle would otherwise appear to do
nothing on this page. Other pages retain the normal theme control.

layouts/partials/meta.html now emits a canonical link for every page.
scripts/validate-subpath.mjs verifies the exact QR3D artifact, canonical URL,
main-site destination, QR artwork, configured social destinations, unique
social markers, compact footer, hidden theme toggle, and subpath-safe assets.
