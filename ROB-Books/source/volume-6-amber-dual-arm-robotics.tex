\ROBFrontMatter{A model is not a safety certificate}{Understand every frame before commanding motion.}{%
This volume documents the two AMBER B1 arms from the checked-in Ubuntu snapshot, Python API, launch configuration, and robot-description files. It distinguishes directly observed formats from assumptions, identifies contradictions that must be resolved on the real machine, and begins every commissioning path with power removed or motion disabled.

The archived core executables are binaries, not complete source. This book can reproduce the observed runtime envelope, configuration, and client protocol; it cannot prove how the proprietary core implements every CAN transaction or rebuild those executables from source.
}

\begin{safetybox}[title={POWERED ARMS CREATE CRUSH, PINCH, AND IMPACT HAZARDS}]
Use a qualified adult lead, a verified independent emergency stop, current and speed limits, physical clearance, controlled power, and a spotter. Perform discovery and status tests before enabling torque. Never stand inside either arm's swept volume, and never infer a safe limit from a URDF or example script.
\end{safetybox}
